# Установка Visual Studio Code, расширения Live Server и запуск простой HTML-страницы

Ниже приведена подробная пошаговая инструкция, составленная на основе последовательности скриншотов. Инструкция описывает процесс скачивания и установки Visual Studio Code, установку расширения Live Server, создание рабочей папки и HTML-файла, а также запуск страницы через локальный сервер.

---

## Шаг 1. Поиск VS Code в Google

1. Откройте браузер (в примере используется Google Chrome).
2. Перейдите на сайт **www.google.com** (адрес виден в адресной строке).
3. В поле поиска введите запрос **`vscode`**.

## Шаг 2. Переход на официальный сайт

1. В результатах поиска Google найдите первую ссылку с заголовком **«Visual Studio Code – The open source AI code editor | Your …»** (адрес `https://code.visualstudio.com`).
2. Нажмите на эту ссылку, чтобы перейти на официальный сайт Visual Studio Code.

## Шаг 3. Скачивание установочного файла

1. На сайте `code.visualstudio.com` откроется главная страница с заголовком **«The open source AI code editor»**.
2. В центре страницы нажмите на чёрную кнопку **«Download for Windows»** (если у вас другая операционная система, сайт автоматически предложит соответствующую версию).

## Шаг 4. Ожидание начала загрузки

1. После нажатия откроется новая вкладка с адресом вида `code.visualstudio.com/thank-you?dv=win64user`.
2. На странице появится сообщение **«Your download of Visual Studio Code should start shortly»** — загрузка файла начнётся автоматически. Если этого не произошло, воспользуйтесь ссылкой **«Direct download link»**.

## Шаг 5. Запуск установочного файла

1. Откройте папку **«Загрузки» (Downloads)** через Проводник Windows (This PC → Local Disk (C:) → Users → [имя пользователя] → Downloads).
2. Найдите скачанный файл с именем вида **`VSCodeUserSetup-x64-1.137.0.exe`**.
3. Дважды щёлкните по файлу, чтобы запустить установщик.

## Шаг 6. Принятие лицензионного соглашения

1. В открывшемся окне установщика **«Setup – Microsoft Visual Studio Code (User)»** отображается лицензионное соглашение.
2. Установите переключатель **«I accept the agreement»**.
3. Нажмите кнопку **«Next»**.

## Шаг 7. Выбор папки установки

1. На экране **«Select Destination Location»** оставьте предложенный по умолчанию путь установки (например, `C:\Users\<имя_пользователя>\AppData\Local\Programs\Microsoft VS Code`).
2. При необходимости измените путь через кнопку **«Browse…»**.
3. Нажмите **«Next»**.

## Шаг 8. Выбор папки в меню «Пуск»

1. На экране **«Select Start Menu Folder»** оставьте название папки по умолчанию — **«Visual Studio Code»**.
2. Нажмите **«Next»**.

## Шаг 9. Дополнительные задачи

1. На экране **«Select Additional Tasks»** можно отметить дополнительные пункты, например:
   - Create a desktop icon (создать ярлык на рабочем столе);
   - Add "Open with Code" action to Windows Explorer file context menu;
   - Add "Open with Code" action to Windows Explorer directory context menu;
   - Register Code as an editor for supported file types (отмечено по умолчанию);
   - Add to PATH (requires shell restart) (отмечено по умолчанию).
2. Оставьте отмеченные по умолчанию пункты (последние два) и нажмите **«Next»**.

## Шаг 10. Подтверждение установки

1. На экране **«Ready to Install»** проверьте параметры установки (папка назначения, папка в меню «Пуск», дополнительные задачи).
2. Нажмите кнопку **«Install»**, чтобы начать установку.

## Шаг 11. Процесс установки

1. Дождитесь завершения установки — на экране **«Installing»** отображается индикатор прогресса и список извлекаемых файлов.

## Шаг 12. Завершение установки

1. На экране **«Completing the Visual Studio Code Setup Wizard»** оставьте отмеченным пункт **«Launch Visual Studio Code»**, чтобы программа запустилась сразу после установки.
2. Нажмите кнопку **«Finish»**.

## Шаг 13. Первый запуск VS Code

1. После запуска откроется главное окно Visual Studio Code.
2. Вверху появится уведомление **«Restricted Mode is intended for safe code browsing. Trust this window to enable all features»**.
3. Нажмите на ссылку **«Manage»**, расположенную рядом с этим уведомлением.

## Шаг 14. Управление доверием к рабочей области (Workspace Trust)

1. Откроется вкладка **«Workspace Trust»** с заголовком **«You are in Restricted Mode»**.
2. В левом блоке **«In a Trusted Window»** нажмите синюю кнопку **«Trust»** (можно также использовать сочетание клавиш Ctrl+Enter), чтобы разрешить полный функционал редактора.

## Шаг 15. Подтверждение доверенного режима

1. После нажатия кнопки заголовок изменится на **«This window is trusted»**, а слева появится подтверждение, что все функции включены (Tasks are allowed to run, Debugging is enabled, All enabled extensions are activated).
2. Закройте вкладку **«Workspace Trust»**, нажав на крестик (**X**) в правом верхнем углу вкладки.

## Шаг 16. Поиск расширения Live Server

1. Откройте раздел **«Extensions» (Расширения)** на боковой панели слева (иконка с квадратами).
2. В поле поиска введите **«live server»**.
3. В списке результатов найдите расширение **«Live Server»** от автора **Ritwick Dey** (значок в виде фиолетового круга с волнами Wi-Fi) — оно описывается как *«Launch a development local Server with live reload feature for static & dynamic pages»*.
4. Нажмите на это расширение, чтобы открыть страницу с подробным описанием.

## Шаг 17. Установка и включение расширения Live Server

1. На странице расширения **«Live Server»** нажмите кнопку **«Install»**.
2. После установки расширение появится в списке **«Installed»** на боковой панели (вместе с ранее установленными расширениями, например **Vim**).
3. Обратите внимание: расширение может быть установлено, но **отключено именно для текущей рабочей области** — в этом случае кнопка рядом с ним будет называться **«Enable»** и иметь рядом стрелку выпадающего списка.
4. Нажмите на стрелку выпадающего списка рядом с кнопкой **«Enable»**.
5. В появившемся меню выберите пункт **«Enable (Workspace)»**, чтобы включить расширение именно для текущей рабочей области (папки проекта).

## Шаг 18. Создание новой папки на рабочем столе

1. Сверните VS Code и перейдите на рабочий стол Windows.
2. Щёлкните правой кнопкой мыши по пустому месту рабочего стола, чтобы открыть контекстное меню.
3. В меню выберите пункт **«New» (Создать)**, а затем в появившемся подменю выберите **«Folder» (Папка)**.

## Шаг 19. Присвоение имени папке

1. Новой папке автоматически предлагается ввести имя — введите **«lab1»**.
2. Нажмите Enter, чтобы подтвердить имя папки.

## Шаг 20. Открытие папки в VS Code

1. Вернитесь в окно Visual Studio Code.
2. На боковой панели слева откройте раздел **«Explorer»** (иконка листа бумаги, если он ещё не открыт).
3. Поскольку папка ещё не открыта, появится сообщение **«You have not yet opened a folder»**.
4. Нажмите кнопку **«Open Folder»**.

## Шаг 21. Выбор папки lab1

1. В открывшемся диалоговом окне **«Open Folder»** перейдите в раздел **«Desktop»** на левой панели.
2. Выберите (или введите в адресной строке) папку **«lab1»**, созданную на шаге 19.
3. Нажмите кнопку **«Select Folder»**.

## Шаг 22. Папка lab1 открыта в редакторе

1. После выбора папки VS Code перезагрузит окно, и в панели **«Explorer»** слева появится папка **«lab1»** (пока пустая).
2. Убедитесь, что вкладка «Welcome» открыта в основной области редактора.

## Шаг 23. Создание нового файла

1. В панели **«Explorer»** наведите курсор на название папки **«lab1»**, чтобы появились иконки управления.
2. Нажмите на иконку **«New File…»** (первая иконка со значком листа со плюсом) в верхней части панели Explorer.

## Шаг 24. Ввод имени файла

1. Появится поле для ввода имени нового файла внутри папки **lab1**.
2. Введите имя файла: **`index.html`**.
3. Нажмите Enter, чтобы создать файл.

## Шаг 25. Ввод содержимого файла

1. Файл **index.html** откроется в основной области редактора (пустой, с курсором на первой строке).
2. Введите в первой строке файла слово: **`Welcome`**.

## Шаг 26. Сохранение файла

1. Откройте меню **«File»** в верхней панели меню VS Code.
2. В открывшемся меню выберите пункт **«Save»** (либо используйте сочетание клавиш **Ctrl+S**).

## Шаг 27. Запуск файла через Live Server

1. В панели **«Explorer»** щёлкните правой кнопкой мыши по файлу **index.html**.
2. В появившемся контекстном меню выберите пункт **«Open with Live Server»**.

## Шаг 28. Просмотр результата в браузере

1. Автоматически откроется браузер с адресом вида **`http://127.0.0.1:5500/index.html`** — это локальный сервер, запущенный расширением Live Server.
2. На странице должно отображаться слово **«Welcome»**, введённое на шаге 25.
3. Live Server также поддерживает автоматическое обновление страницы: при изменении и сохранении файла index.html содержимое в браузере обновится без ручной перезагрузки страницы.

---

### Итог

В результате выполнения всех шагов вы:
- скачали и установили Visual Studio Code с официального сайта;
- разрешили полный доступ к функциям редактора (Trust the workspace);
- установили расширение **Live Server**;
- создали рабочую папку **lab1** и файл **index.html**;
- запустили файл через локальный сервер и увидели результат в браузере.
